# CodeAlpha Internship — Two Completed App Development Tasks

This package contains two standalone web apps built with HTML, CSS and JavaScript.

## Task 1: Flashcard Quiz App
Features:
- Shows a question and reveals its answer with the Show Answer button.
- Previous and Next navigation.
- Add, edit and delete flashcards.
- Saves the deck in browser localStorage.

## Task 2: Random Quote Generator
Features:
- Displays a random quote when the page opens.
- New Quote button selects another quote.
- Shows both quote text and author.
- Avoids showing the same quote twice in a row.

## How to run
1. Extract this ZIP file.
2. Open `task1_flashcard_quiz/index.html` in a browser to run Task 1.
3. Open `task2_random_quote_generator/index.html` in a browser to run Task 2.
4. Internet is not required. No installation is needed.

## How to upload to GitHub
1. Sign in to GitHub and create a new public repository named `CodeAlpha_TwoProjects`.
2. Extract the ZIP file on your computer.
3. Open the repository page, choose **Add file → Upload files**, and upload both task folders.
4. Commit the changes.
5. To publish one app, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)` if publishing from the root. For each task separately, easiest is to create a separate repository for each folder and enable Pages.
6. Wait for GitHub Pages to publish, then open the provided website URL and test it.
